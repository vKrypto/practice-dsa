## 3. Real-Time AR Jewellery Try-On

**Timeline:** Jan 2024 – Jun 2024
**Company:** Ornaz Jewellery Pvt. Ltd.
**Role:** Software Developer Intern

### Project Overview

Real-Time AR Jewellery Try-On is a browser-based augmented reality solution that allows customers to virtually try jewellery items using real-time hand tracking.

### Problem Statement

Online jewellery customers often struggle to visualize how a product will look before purchasing. This lack of visualization can reduce confidence and affect conversion.

### Solution

Developed a browser-based AR try-on experience using MediaPipe hand tracking. The system detected hand landmarks and placed jewellery virtually in real time, helping users visualize products before buying.

### Tech Stack

MediaPipe, JavaScript, HTML5, CSS3, Browser APIs

### Key Responsibilities / Bullet Points

* Developed a browser-based AR jewellery try-on solution.
* Used MediaPipe for real-time hand tracking and landmark detection.
* Implemented jewellery placement based on detected hand positions.
* Optimized rendering performance for smoother browser interactions.
* Improved customer engagement through interactive product visualization.
* Contributed to frontend innovation during internship.

**Role:** Software Developer

Lead Assistant is an internal GenAI-powered multi-agent platform built to automate lead generation, lead qualification, personalized outreach, follow-ups, conversational assistance, and sales analytics.
